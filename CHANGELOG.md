## [0.0.1] - 2026-11-23

### Added
- Project foundation: `devlens` Python package with a Typer CLI (`--version`, `info`).
- Tooling: uv, ruff, mypy (strict), pytest with an 80% coverage floor, pre-commit.
- CI on GitHub Actions: lint, types and tests on Python 3.11 – 3.14.
- Documentation: bilingual README, `AI_WORKFLOW.md`, `DECISIONS.md`, ADRs 0001 – 0005.
